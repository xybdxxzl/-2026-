# 转动的授时图 · 界面设计规范

更新：2026-11-05。适用：现有 Vue 3 / Vite / SVG 交互作品。

## 设计依据

使用 UI/UX Pro Max 检索 `museum gallery heritage`。采用其博物馆叙事中的篇章连续性、清晰阅读次序、克制动效和高对比排版建议；保留项目既有的中国古籍、纸墨与四季颜料体系。检索返回的黑白画廊配色与西文字体不直接用于本项目。

Vue 的 `responsive accessible components` 与 `accessibility` 两次查询均无匹配，具体实现以已有 Vue 组件和技能通用可访问性规则为准。标题排版另检索 `orphan heading line balance`，使用渐进增强的平衡换行，不插入固定换行或不换行空格。

## 视觉变量

定义入口：`web/src/style.css` 的 `:root`。

| 语义 | 值 | 用法 |
| --- | --- | --- |
| 纸色 | `#f6f3ea` | 页面底色 |
| 阅读表面 | `#fcfaf3` | 当令札记、图表、候象卡片 |
| 次级表面 | `#eeeee4` | 分段选择、辅助说明 |
| 墨色 | `#243e36` | 正文、主标题、主要操作 |
| 次级文字 | `#626c60` | 标签、注释、资料状态 |
| 朱砂 | `#9e4935` | 当前选择、聚焦轮廓、关键提示 |
| 青绿 | `#3d6553` | 阅读链接、次级强调 |
| 描边 | `#d6d8c9` | 分隔线、阅读表面边界 |

标题使用系统宋体字体栈，正文与控件使用系统中文无衬线字体栈，数字使用 Georgia。无需加载在线字体。正文以 14–16px 为主，辅助文字以 11–13px 为主。正文行高 1.6–2；每个篇章保留一个 h1。

## 页面与控件

- 首页：引题 → 左侧转盘 / 右侧当令札记 → 全年节气轴 → 三候 → 其他篇章入口。侧栏的朱砂标记和深墨主按钮建立主次层级。
- 日晷：先展示日晷和一日控制，再展示全年节气轴与两至两分比较。
- 农事与古图：统一标题、分段选择、资料状态和阅读表面的样式，保留横向长卷与原图留白。
- 用 SVG 图标统一箭头、帮助、关闭等操作；图标为装饰时从可访问性树中隐藏。
- 顶部箭头、帮助与关闭控件保持清晰点击区域。选择按钮暴露 `aria-pressed`，展开按钮暴露 `aria-expanded`。
- 操作指南与出处面板打开时，背景设为 inert；焦点进入面板、Tab 在面板内循环，Esc 关闭后在 DOM 更新完成后返回触发按钮。
- 细读为页内展开区域。展开时焦点落在可见标题，收起时返回触发控件。更换篇章后焦点进入正文。

## 响应式与动效

- 主内容最大宽度 1520px；800px 及以下首页改为单列。
- 480px 及以下三候卡片改为横向插画与文字的单列卡片。
- 小屏节气轴保留可横向阅读的曲线，同时提供原生节气滑块；触屏横向滚动不与图表拖动争抢手势。
- 全年竖表曲线也在窄屏中独立滚动，不让页面整体溢出。
- 非几何反馈采用约 150–300ms 的短过渡，保留原有转盘惯性物理模型。
- 遵循系统及用户“减少动态效果”选择。候象、粒子和过渡沿用已有动态控制。

## 必须保留的产品规则

节气在扇区中心、三候位于 −5° / 0° / +5°。按 2026-11-05 用户确认方案，全年七十二候完整显示，当前三候以淡底色突出，当前一候以朱砂与圆点共同强调；下半圈文字自动翻正。切换候象不改变所属节气的主盘居中。日晷与八尺竖表的模型和单位保持区分。候名初稿、农事示例、历史资料待核验的标记保持可见，不填造史料。

圆心直径扩大到 396 SVG 单位，采用固定朝向的铜色晷面、青铜色晷针与午正投影；投影与现有 `sundialModel` 共用同一模型，不按季节缩放。圆心可以点击、Enter 或 Space 进入观天测影。全年竖表精确比较由下方曲线承担，原首页放射日影环不再显示。

转盘容器宽度不超过 600px 时提供三候放大阅读区，候名完整换行。保留 44px 前后按钮及逐候方向键选择，对应 UI/UX Pro Max `dragging movements` 检索中的非拖动操作替代建议。

## 2026-11-05 验收

26 项逻辑测试和生产构建通过。新增测试覆盖全年 360 个经度的日晷影端范围、午正投影与竖表模型的关系、冬夏影端变化，以及晷面厚度不侵入候名环带。浏览器逐项检查全部 24 节气均显示 72 个候名、3 个当前候、1 个朱砂候；点其他节气候名、逐候方向键跨界、圆心跳转均通过。320×740、375×812、812×375、768×1024、1024×768、1440×900 未见整页横向溢出；手机八字候名完整换行。

## 2026-10-31 验收记录

现有 23 项逻辑测试和生产构建通过。浏览器检查首页在 375×812、812×375、768×1024、1024×768、1366×768、1920×1080 下无整页横向溢出；手机端农事、日晷、古图、资料页同样通过宽度检查。验证了指南焦点循环与返回、三候/69 刻度、窄屏节气滑块及图表跟随、节气跨篇章保留、日晷播放暂停和切换节气保留时刻。检查期间应用控制台无警告和错误。

这些检查不等同于完整 WCAG 审计；最终参赛设备的长时性能验收仍按项目原有计划进行。
