# 转动的授时图

《转动的授时图》是一件围绕二十四节气的交互作品。在首页转动年轮，可以读一个节气的三候、查看农事线索，或从圆心的日晷进入「观天测影」。观测页提供两件可以转动和读影的三维日晷，以及一把分别调节日期和真太阳时的授时尺。

## 快速启动

需要 Node.js 22.12 或更高版本和 npm。首次使用，在仓库根目录打开终端运行：

```sh
cd web
npm ci
npm run dev
```

打开终端打印的本地地址。Windows 安装依赖后，可以按演示需要双击仓库根目录的启动脚本：

- [预览三维日晷.cmd](../预览三维日晷.cmd) 直接打开「观天测影」。先看赤道晷的盘缘与支架，点击「碗式」可对照碗沿、内壁和珠影。
- [启动原型.cmd](../启动原型.cmd) 从首页的授时转盘开始浏览整部作品。

两个入口都从 `127.0.0.1:5173` 起寻找可用端口，并自动打开默认浏览器。演示期间保留启动窗口，按 Ctrl+C 即可停止。

## 观天测影

**两件器物。** 两款三维器物采用浅铜材质与暖白石座。赤道式日晷的晷针平行地轴，可查看正面、背面或直接定位受影面，读数给出影长与晷针长之比。碗式日晷用球心铜珠投影，俯看碗内可读时线、节气线和珠影，水平偏移以碗内半径 R 为单位。两款器物均支持斜视、侧视、北侧、南侧，以及各自的晷面正视或碗内俯视。桌面可拖动旋转、滚轮缩放，触屏可启用「触摸旋转」。

**地点与时间。** 「按日期观测」使用当地日期、钟表时间和时区；「按节气比较」可在同一真太阳时比较节气。默认地点是阳城 · 登封告成，也可选择北京、悉尼、特罗姆瑟等预设地点，或输入经纬度、海拔和 IANA 时区。日期范围为 2025-01-01 至 2029-02-10，比较支持 2025 至 2028 四个立春周期。交节卡可跳至交节瞬间或当天午正。复制观测页完整地址可恢复地点、时刻、观测模式和所选节气；碗式器型由 `dial=bowl` 指定。

**授时尺与对照。** 画布下沿可直接播放或暂停，当前真太阳时、日轴与岁轴依次排列。 「岁」轴选择日期或节气，保留当前真太阳时；「日」轴逐分钟调整真太阳时，标出日出、日落，可播放一天、前后移动 15 分钟或回到当地午正。「二至对照」从午正侧视开始，可切换由夏至或冬至驱动日照，同一张读数表用朱红标出夏至、青蓝标出冬至，列出太阳高度、八尺表影长及差值。桌面读数表位于画框右侧，窄屏移到画布下方。观测页下方可展开所选地点的全年午正竖表影长曲线，单位为尺。

**天球与图层。** 画框上沿的「展开天球」在器物外围显示地平圈、天赤道、黄道与节气刻度，日落后展台渐转为浅青灰，恒星随天色渐显，点击「回看日晷」可收回视野；星表收录 288 颗恒星。天球采用外视视角，页面标注了星象方向与示意比例。「光影关系」可显示投影路径；「图层与画质」可控制太阳轨迹、影端轨迹、方位、轻量画质以及二维视图。三维场景按需加载，WebGL 不可用时自动切换到对应器型的二维 SVG。[星表来源与许可](src/data/sundialStars.SOURCE.md)

### 一次演示

1. 在首页选择夏至，点击圆心日晷进入「观天测影」。
2. 选择「碗式」和「俯看碗内」，打开「光影关系」。在「日」轴从上午拖到午正，沿入射光线观察珠影如何经过内壁刻线。
3. 回到「斜视」，点击「展开天球」，将日轴拨过日落，观察太阳相对地平圈的位置和星点变化。
4. 点击「回看日晷」，打开「二至对照」，在同一真太阳时比较冬、夏两束光与八尺表的地面投影。

## 实现与验证

前端使用 Vue 3、Vue Router 和 Vite，年轮与二维图使用 SVG，三维场景使用 Three.js。Astronomy Engine 计算太阳位置及交节，Temporal polyfill 处理当地时区与 UTC 的转换。天文计算和内置参考数据均在浏览器本地运行。观测值基于几何太阳高度和理想地面；历史器物形制与观测地点仍需史料考证。

在 `web/` 目录运行：

| 命令 | 用途 |
| --- | --- |
| `npm test` | 运行 Node.js 自动化测试，覆盖年轮、日晷几何、授时尺、交节、时区和天球等。 |
| `npm run build` | 生成静态站点到 `web/dist/`。 |
| `npm run preview` | 构建后在本机预览生产产物，访问终端打印的地址。 |

2026-11-19 在 Node.js 24.16.0 下实测：65 项测试全部通过，生产构建成功。交节测试覆盖 101 个节点，计算结果与香港天文台及台北市立天文科学教育馆收录的参考分钟时刻相差均在 60 秒以内。Vite 对压缩前超过 500 kB 的 JavaScript 分块给出体积提示。[交节对照测试](tests/observation.test.js) · [参考历表与出处](src/data/hkoSolarTerms.js)
