# 转动的授时图 · 本地交互原型 v0.2

Vue3 + Vite + Vue Router + SVG。保留四个主题篇章，观天测影以水平式日晷为主。本轮交互规格与验证详见根目录《交互与动效_实现说明.md》。

## 启动

从Windows资源管理器双击项目根目录的“启动原型.cmd”。启动窗口保持开启，浏览器会自动打开实际可用地址；端口被占用时自动递增。不要把聊天中的文件编辑器预览误认为已经运行启动脚本。

也可在本目录执行：

```text
npm run dev
npm test
npm run build
```

需要Node.js 22.12或更新版本；依赖已在本地安装。启动脚本为ASCII、CRLF，支持中文及含空格路径。生产构建输出在dist/，运行时资源本地化。

## 当前可操作内容

- 共用连续年角：转盘、节气轴、日晷、候象与季相同步；选定节点写回URL，四篇保持节气和地域。
- 转盘支持拖动、甩动惯性、弹簧吸附、滚轮、左右键、Home、Enter细读、Esc收起。点击节气沿最短路径转动。
- 节气轴支持鼠标拖动、点击、方向键±5°、PageUp / Down±15°、Home / End。全年曲线是八尺竖表正午影长，不是日晷晷针的影端距离。
- 日晷保留原有全天时刻滑块、日行播放、夜间无影、两至两分比较。年轴改节气时保留当前真太阳时。主绘图轻微平滑追随，落定时影端反馈。
- 季相色彩连续变化，含雨、雪、远处柔和雷光、雾、落叶。是艺术示意，不是历史气象数据。
- 72候名称为团队初稿；10组动态SVG，其余共享静态线描类型。点击候卡片或十动画索引可定位一候；拖动时静止、落定后播放。
- 惊蛰、芒种、夏至、小雪提供显式示例农事与农谚。可从“随谚寻时”跨节气定位，并双向、跨南北高亮。所有示例都标注“示例 / 待核对”。
- 档案有来源返回与迷你转盘返回。采用页面内圆形展开转场，普通篇章使用淡入与位移，快速新操作取消旧转场。

D键或debug=1开启调试。页脚“减少动态效果”默认遵循系统，可主动切换；开启后无粒子、雷光、候象循环与弹簧过渡。后台页面暂停动画循环；低帧率下粒子分级减量。

## 模型与资料

当前纬度35°N、黄赤交角23.44°、竖表八尺均为演示参数。水平式日晷采用极轴晷针和按纬度计算的时线，晷针垂直高度归一化；不冒充历史器物复原，不直接换算北京时间。忽略折射、太阳视半径、地形等。

历史原图、区域案例、谚语出处、准确交节日期与模型地点仍需核验。“资料研究/2026-10-29_第一批”保留真实来源研究草稿；本轮没有把草稿直接当作最终内容录入。

静态候象可在src/assets/hou/中用lichun-1.svg等候ID命名的本地SVG替换，建议viewBox为0 0 240 160。十动画映射和72候名称在src/data/hou.js，关系示例在src/data/linkedRecords.js，物理与粒子上限在src/core/tuning.js，季相在src/core/season.js。

当前路由/sky实际使用SundialView.vue；早期SkyView.vue、ShadowDiagram.vue属于未使用的旧原型。

## 本轮验证与限制

14项逻辑测试及生产构建通过。实际浏览器验证了转盘惯性与落定、年轴拖动与键盘微调、保留时刻、候象选择、双向关联、第二层常驻日晷、档案返回、快速操作取消旧导航、雨雪与减少动态效果；1280×720、1366×768、2560×1440无整页横向溢出，控制台无错误。

调试帧率仅反映当前环境，尚未对最终参赛笔记本做长时间60fps保证。其余62候仍为通用静态示意，未各自完成独立考据插画；农谚与农事内容及其关系仍为明确占位。

## 假设与待确认

沿用既有JavaScript工程，不因参考稿迁移TypeScript或增加Pinia、D3、动画库。保留日晷主体与35°演示纬度，不回退为原来的竖表主界面。不使用粗略日期冒充准确“今日定位”。参赛方向已由用户确认，不再作为开发阻塞项。

转场取舍：原生整页快照在快速连点时会吞掉输入，最终使用不冻结页面的CSS圆形裁切。参考：[View Transition API](https://developer.mozilla.org/en-US/docs/Web/API/Document/startViewTransition)；[水平式日晷原理](https://sundialsoc.org.uk/all-about-sundials/how-sundials-work/how-sundials-work-part-2/)。
