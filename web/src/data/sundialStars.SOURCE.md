# 日晷夜空星表

`sundialStars.json` 取自 David Nash／Astronexus 的 [HYG Database v4.1](https://github.com/astronexus/HYG-Database/blob/3bf37f4b2d5460e1278286320d1d62fab9b493c1/hyg/CURRENT/hygdata_v41.csv)，以 [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) 分发。

本文件是修改后的数据摘录。筛选视星等 ≤ 3.5、具有 HIP 编号的恒星，排除太阳和缺少 HIP 编号的三条记录，保留 288 颗恒星。每条记录依次存放 HIP 编号、赤经（小时）、赤纬（度）、视星等，坐标采用原表的 J2000.0 历元及分点。数值沿用原表精度，记录按 HIP 编号排序。

原始 CSV 的 SHA-256 为 `d9f69fd86bbf90a4e4d52b4c5c53eacfa6dfc0bfdef85bfd94f095e0bebe4e4ebd`。
