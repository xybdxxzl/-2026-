## 同机位对比

基线来自上一轮两份结构图的原始三维试模。当时网页已有赤道式，碗式保存在试模中。新版调用观测页正在使用的器物、材质、石纹、光照与阴影程序。前后各对保持相对承影中心的相机方向和按 R 归一化的取景尺度一致。碗式的两张照片一起预留了新石台所需的边距。

固定北纬 34.4°、理想夏至赤纬 +23.44°、真太阳时 10:00（时角 −30°），关闭光线、影端标记、天球和圭表。桌面场景视口为 800 × 510 CSS 像素，手机场景为 390 × 382，均以 2 倍像素密度采集。另在 390 × 844 的浏览器设备模拟和 1440 × 900 桌面页面，使用 2026-06-21 登封告成实际太阳位置切换器型，核对读数。390 宽度的实际页面中，观测画布内宽 349 像素。

## 读数对比度

以下数值均为亮度比，越大越清晰。左为旧试模，右为本次模型。“单独投影”只切换光源投影再取同一位置，可以分辨针影或珠影本身的变化。“影端邻域”保留落点附近本来就有的时线和节气线。

| 场景 | 单独投影 | 影端邻域 | 辰正主时线 | 巳字 |
| --- | ---: | ---: | ---: | ---: |
| 赤道式 · 桌面 | 2.15 → 2.59 | 3.47 → 11.21 | 1.69 → 8.83 | 5.47 → 10.83 |
| 碗式 · 桌面 | 2.93 → 3.31 | 7.46 → 10.43 | 2.61 → 12.05 | 1.31 → 11.99 |
| 赤道式 · 390px | 2.09 → 2.42 | 3.15 → 11.38 | 1.49 → 9.57 | 4.12 → 10.74 |
| 碗式 · 390px | 2.98 → 3.31 | 5.76 → 8.71 | 1.89 → 12.68 | 1.25 → 12.43 |

先按 sRGB 转线性相对亮度 Y。时线取辰正线，赤道式采样半径 0.48R，碗式采样赤纬 −5°。文字取同一“巳”字中心。赤道式影端取针影长度的 90% 处，避开零宽的数学尖点；碗式取解析珠影中心。所有取样点都从三维坐标投影到原片。以影端、时线、文字为中心，桌面邻域半径分别为 5、4、9 个 CSS 像素，手机分别为 4、3、7 个。对每个方形邻域取 (P90(Y)+0.05)/(P5(Y)+0.05)。单独投影使用同一影端邻域，逐像素算 (Y关闭投影+0.05)/(Y开启投影+0.05)，报告第 95 百分位。测量使用未经缩放的浏览器原片。

## 色相与铜绿

对桌面与手机的两款斜视，另渲染无照明的材质识别图，将器物像素映射回真实渲染。每种材质的主色相取非中性像素在 1° HSV 色相区间中的众数。

| 部位 | 实际渲染主色相 |
| --- | ---: |
| 汉白玉承影面 | 42° |
| 暖灰石台 | 41° |
| 古铜耳座、盘缘、晷针、碗唇、铜珠 | 24° |
| 暗铜细线与轴 | 13° |
| 金色铜件高光部 | 32° |
| 深褐漆铜碗壁与圈足 | 20° |
| 朱砂北刻 | 8° |

在两款器物的正立面、侧立面、承影面正视、桌面斜视和手机斜视共 10 个画面中，以不透明器物轮廓为面积分母，单独绘制凹槽铜绿材质并累计抗锯齿覆盖。铜绿占比最高 **0.0283%**，两款手机场景均为 **0%**。另对最终彩色像素计数，80°–170° 色相像素在单张器物中的最高占比为 0.0358%。后一个数值也包含细线混色产生的像素。
